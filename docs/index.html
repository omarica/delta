Judge it on code size, not tokens. Viral videos claim 50%+ token savings; the top reply cites the docs saying that is not its purpose.

SKIP · Plugins

Treat "unlimited free usage" routers with suspicion

Before installing a router that pools free third-party providers, read its source: your prompts and code pass through it. Unverified community warning, not a confirmed finding.

A plugin-stack video promoting one drew a 'do not install' reply; verify yourself.
